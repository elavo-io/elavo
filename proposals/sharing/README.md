# Sharing (LocalSend)

System Settings > General > Sharing is LocalSend only: receive from,
favorites, auto-accept, save folder, and PIN. Those settings live in
elavo-system-settings. The image needs no extra packages or units for
Sharing.

The polkit action `io.elavo.Sharing.reveal-secret` (Show PIN) is installed
with System Settings (`data/io.elavo.Sharing.policy`).
